# Design reference — PolicyGuard dashboard

This directory holds the **design source of truth** for PolicyGuard's GUI (the HTML
scan-results dashboard).

- **`DESIGN.md`** — the terminal-mono design guidelines (monospace, near-monochrome
  dark canvas, one accent, severity-semantic color, hand-built textures). Inherited
  from a crypto-dashboard design language and adapted for a security tool.
- **`mockup.html`** — the approved reference render of the PolicyGuard dashboard
  (a bundled SPA used only as a visual target). The shipped GUI is **not** this
  SPA — it is generated by the tool (`pkg/reporter/html`) from real scan data.

The operating contract for building/reviewing the GUI lives in the skill
`.claude/skills/policyguard-dashboard/SKILL.md`, which adapts these guidelines and
adds the **honest-data contract**: the dashboard renders only real findings,
counts, CWE mappings, evidence, and remediation produced by an actual scan —
nothing is mocked.

To regenerate the committed sample report from a real scan:

```bash
go build -o bin/policyguard ./cmd/policyguard
bin/policyguard scan examples/terraform --format html -o docs/design/sample-report.html
```
